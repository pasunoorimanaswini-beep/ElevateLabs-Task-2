# My To-Do List (Vanilla JavaScript)

A front-end only to-do app: HTML + CSS + JavaScript, no libraries.

**Features:** add tasks (with priority and due date) · mark complete with a checkbox (confetti!) · delete · click a task to edit · All / Pending / Completed filters · progress ring · dark mode · saved in localStorage · responsive.

**Run:** open `index.html` in a browser.
